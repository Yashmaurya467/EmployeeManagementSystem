# Employee Management System

## About the Project
A web-based Employee Management System developed using Java,
JDBC, Servlet, JSP and MySQL.

## Technologies Used
- Core Java
- JDBC
- Servlet
- JSP
- MySQL
- Maven
- Apache Tomcat

## Features
- Employee Registration
- Employee Login
- View Employee Details
- Update Employee Details
- Delete Employee Details
- Session Management
- Logout
- Exception Handling

## Project Architecture
DAO → Service → Controller/Servlet → JSP

## Database
MySQL is used to store and manage employee records.

## How to Run
1. Clone the repository
2. Import the project into Eclipse
3. Configure MySQL database
4. Update database configuration
5. Run the project on Apache Tomcat
